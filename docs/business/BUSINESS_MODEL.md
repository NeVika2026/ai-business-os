## Executive summary

AI Business OS is not sold as AI software. It is sold as **business progress on demand** — saved time, better decisions, completed work, and measurable growth. Revenue comes from subscriptions tied to outcomes and usage value, not from exposing tokens, agents, or runtime complexity.

The company wins when users return daily, complete meaningful work weekly, and expand into more projects, seats, and business domains over time.

## Ideal customer profiles (ICPs)

### ICP 1 — Solo business operator (primary)

| Attribute | Detail |
| --------- | ------ |
| **Who** | Owner-operator, consultant, freelancer, broker, agency-of-one |
| **Team size** | 1–5 people |
| **Revenue** | $50K–$2M annual |
| **Pain** | Too much to do, no dedicated ops/marketing staff, scattered tools |
| **Buying trigger** | Needs a client plan, outreach sequence, or decision framework this week |
| **Success signal** | Completes first result in one session; returns within 7 days |

### ICP 2 — Growth-stage small business

| Attribute | Detail |
| --------- | ------ |
| **Who** | Founder with 5–25 employees, marketing lead, ops manager |
| **Team size** | 5–25 |
| **Revenue** | $500K–$10M annual |
| **Pain** | Coordination overhead, inconsistent follow-through, knowledge in people's heads |
| **Buying trigger** | Wants one place for goals, projects, and completed work — not another AI toy |
| **Success signal** | Multiple projects active; 3+ results per week; one champion user |

### ICP 3 — Vertical specialists (beachhead)

| Attribute | Detail |
| --------- | ------ |
| **Who** | Real estate brokers, MLM leaders, local service businesses, content-led brands |
| **Why beachhead** | Repeatable jobs-to-be-done; strong word-of-mouth in tight communities |
| **Success signal** | Vertical-specific templates and recommendations accepted at high rate |

### Anti-ICP (do not optimize for yet)

- Enterprise IT buyers requiring SSO, audit, and procurement cycles
- Developers building on APIs
- Hobbyists exploring AI with no business outcome
- Teams that want to configure agents and orchestration graphs

## Jobs-to-be-done (JTBD)

Users hire AI Business OS to make progress on business goals, not to operate software.

| Job | User language | Platform delivery |
| --- | ------------- | ----------------- |
| **Get unstuck** | "I don't know where to start" | Guided goals, intent confirmation, first result |
| **Win clients** | "I need more clients" | Audience analysis, outreach plan, acquisition strategy |
| **Grow revenue** | "I need more sales" | Funnel review, priority actions, revenue plan |
| **Ship work** | "I need this done today" | Completed deliverable saved to project |
| **Stay organized** | "Everything is scattered" | Projects, history, continue where you left off |
| **Move faster** | "I don't have time" | Invisible preparation; user confirms intent, gets result |

When evaluating product and pricing, ask: **Did we complete the job?** Not: **Did we run the model?**

## Revenue streams

### 1. Core subscription (primary)

Monthly or annual plans based on **business capacity**, not AI consumption.

| Dimension | Examples |
| --------- | -------- |
| Active projects | 1 / 5 / unlimited |
| Results per month | Soft caps with fair overage |
| Seats | Owner + team members (future) |
| History & continuity | Return tomorrow, continue work |

### 2. Expansion revenue

| Lever | Mechanism |
| ----- | --------- |
| **Seat expansion** | Add team members who share projects and results |
| **Capacity upgrade** | More projects, higher result limits, priority processing |
| **Vertical packs** | Real estate, MLM, agency playbooks (premium add-ons) |
| **Partner integrations** | CRM sync, calendar, messaging (paid connectors) |

### 3. Services & success (future)

Onboarding for teams, workflow design, and vertical launch kits — high margin, low volume.

### 4. Marketplace & ecosystem (long-term)

Curated templates, certified partners, and revenue share — not open agent marketplace at launch.

## Expansion strategy

### Land

- Free or low-friction trial focused on **one first result**
- Single user, one project, clear upgrade moment after value

### Expand

| Stage | Motion |
| ----- | ------ |
| **Within user** | More goals per week → more projects → history as asset |
| **Within team** | Invite colleague to shared project |
| **Within account** | Upgrade tier when hitting limits after repeated value |
| **Within vertical** | Specialized packs after proven job completion |

### Expansion triggers (product + sales)

- User completes 3+ results in 14 days → suggest Pro
- User creates 2+ projects → suggest team seat
- User exports or shares result → suggest collaboration tier
- User hits monthly result cap on day 20 → upgrade prompt with usage summary

## Enterprise strategy (future)

Not a near-term GTM motion. Document now to avoid building the wrong foundation.

| Phase | Focus |
| ----- | ----- |
| **Now** | Single org, magic-link auth, outcome UX |
| **Year 1** | Team seats, roles, shared projects, basic admin |
| **Year 2** | SSO, audit log, data residency options, SLA |
| **Year 3** | Enterprise tier: procurement, custom verticals, dedicated success |

Enterprise value proposition (future): **Standardize how the organization turns goals into completed business work** — with governance, not with exposed AI infrastructure.

## Partner ecosystem

### Partner types

| Type | Role | Revenue model |
| ---- | ---- | ------------- |
| **Implementation partners** | Onboard SMB clients, configure projects | Referral fee + services |
| **Vertical experts** | Real estate, MLM, agency playbooks | Revenue share on packs |
| **Technology partners** | CRM, email, calendar, storage | Integration listing + rev share |
| **Community advocates** | Educators, coaches, creators | Affiliate / referral credits |

### Partner principles

- Partners sell **outcomes**, not AI seats
- Co-branded vertical packs must preserve invisible-AI UX
- No partner may expose runtime, agents, or orchestration to end users

## Operating model summary

```text
Acquire  → First result (TTFV)  → Habit (weekly results)
    ↓              ↓                        ↓
  Content      Trust + Wow            Retention + expansion
    ↓              ↓                        ↓
 Referral    Recommendation          Upgrade + seats
```

The business is healthy when **Weekly Active Businesses** complete **Business Outcomes** repeatedly — not when token volume grows.
