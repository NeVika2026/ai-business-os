# OSA Audio Assets

Professional recordings replace temporary stubs in this folder.

| File | Role |
| ---- | ---- |
| `sonic-logo.mp3` | OSA sonic logo — main first-contact sting and quiet orbit moment |

If the file is missing, the app falls back to a deep synthesized stub in `utils/first-contact/osa-first-contact-audio.ts`.

Replace `sonic-logo.mp3` with the final studio asset without changing code paths.
